# SNEAKER-HEADS-by-ROCK3TBOYY-
A modern e-commerce starter for a shoe store built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Setup

1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. Open http://localhost:3000

## Features

- Responsive product catalog
- Product details
- Shopping cart with local persistence
- Basic checkout form

## Deployment

Deploy to Vercel: `vercel --prod`
